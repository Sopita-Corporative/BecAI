1.- **¿Qué situación, necesidad o problema quieren atender?**

El problema que nosotros estamos planteando es sobre la oferta de las becas y apoyos económicos para los estudiantes dentro de la universidad de guadalajara, muchas de las veces que se busca una beca surgen varios problemas como: la fragmentación de la información disponible sobre las convocatorias y la baja de participación estudiantil y esto pasa porque las páginas donde se encuentra esta información normalmente son en páginas mal diseñadas y acceder a la información lo hace una tarea difícil y tediosa y es común que sea difícil entender que requisitos solicitan estos apoyos, o simplemente no nos damos cuenta de el gran catálogo de becas y apoyos que existen.

2.- **Objetivo general y objetivos particulares (máximo 4) ¿Qué resultado concreto quieren conseguir con el proyecto?**

1- (Objetivo general) Desarrollar una plataforma web para la organización y publicación de becas para estudiantes, con el fin de centralizar y dar visibilidad a todas las convocatorias.

1.1- Diseñar el modelo entidad-relación y la estructura de la base de datos relacional para organizar la información de los usuarios y las convocatorias de las becas. 

1.2-Desarrollar y programar el backend para gestionar la lógica de usuarios, las convocatoria e implementar un sistema de recomendaciones personalizadas.

1.3-Construir una interfaz de usuario interactiva y responsiva que permita una navegación intuitiva desde cualquier dispositivo.

3.- **¿Qué sí contempla el proyecto?**
El proyecto contempla una creación de usuario enfocándose en datos del perfil académico, un entorno intuitivo en el que se pueda acceder de manera clara y organizada a la información de las convocatorias y recomendaciones personalizadas para cada usuarios

4.- **¿Qué cosas deliberadamente no realizará el proyecto?**
El proyecto no hará registros ni podrá aplicar directamente a las convocatorias o apoyos.

5- **¿Cuál es la versión mínima del proyecto que permitiría demostrar que la propuesta funciona?**

El MVP sería crear un sitio web funcional donde se puedan encontrar diversas becas y apoyos de fácil acceso, con información clara y centralizada. Sin tener que ir a diferentes páginas web, tener la mayoría de becas y apoyos en el mismo sitio web con sus requisitos necesarios y los enlaces de registro.
